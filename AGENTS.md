# Repository Agent Instructions (AGENTS.md)

Rules, constraints, and command references for all AI agents working in this repository.

## 🏗️ Architecture & Stack

- **Backend**: Express/TypeScript state machine using Prisma ORM. Follow role-based access control (RBAC) rules.
- **Frontend**: React/Vite using Panda CSS (Styled System) and Park UI.
- **Accessibility**: Strict compliance with WCAG 2.1 AA.
- **Workspaces**: Multi-package npm workspaces (`-w backend`, `-w frontend`, `-w e2e`).

---

## 🚨 Critical Rules & Constraints

### 1. Color Contrast & Accessibility (WCAG 2.1 AA)

- **Never** use `teal.9` or `amber.9` as solid backgrounds with white text. Use `teal.11` or `amber.11`.
- **Never** use `color: 'color.light.11'` text on a `color.light.2` background badge. Always use `color: 'color.light.12'`.
- **Never** use `fg.subtle` for readable instruction blocks. Use `fg.muted`.
- Any active user interface boundary (like underlines, borders) must meet a contrast ratio of at least 3.0:1 (use `teal.11` instead of `teal.9`).

### 2. Robust Test Selectors

- **Never** target presentational or styling classes generated by Panda CSS (e.g. `div.bdr_xl`) in E2E tests.
- **Always** structure dashboard layout components using semantic tags (e.g., `<article>` for cards) and target them semantically in E2E tests:
  ```typescript
  const card = page.locator('article').filter({
    has: page.getByRole('heading', { name: projectName }),
  });
  ```

### 3. Repeatable E2E Executions

- **Always** call the database seeding reset tool inside the `beforeAll` block before any assertions run. Run it in the repo-root directory context (`cwd` set to repo root).

## 🛠️ CLI Commands

### Build & Dev

- Build all workspaces: `npm run build`
- Run development servers: `docker compose up -d --build`
- View container logs: `docker compose logs -f`

### Lint & Format

- Run lint checks: `npm run lint`
- Check formatting: `npm run format:check`
- Apply formatting: `npm run format:write`

### Testing

- Run unit/integration tests: `npm test`
- Run backend tests only: `npm test -w backend`
- Run frontend tests only: `npm test -w frontend`
- Run E2E & accessibility tests: `npm run test:e2e`

### Database

- Generate Prisma Client: `npm run db:generate -w backend`
- Run database seed/reset (inside container): `docker compose exec -T backend npm run db:seed -w backend`
- Run database seed/reset (locally on host): `npm run db:seed -w backend`
